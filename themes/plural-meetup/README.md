# Plural Meetup — Hugo theme

A small, dependency-free theme with three views: a **landing page**, a static
**about page** and a **blog**. It ships light, dark and high-contrast modes.

```
themes/plural-meetup/
├── archetypes/         default.md · blog.md · landing.md
├── assets/
│   ├── css/main.css    all three palettes, no external requests
│   └── js/theme.js     theme switcher (dropdown > OS > dark default)
├── layouts/
│   ├── 404.html
│   ├── index.html      landing page: hero + entry cards
│   ├── _default/       baseof · list · single · taxonomy · terms
│   └── partials/       header · footer · head · scripts · cards · …
└── static/favicon.svg
```

## Install

```toml
# hugo.toml
theme = "plural-meetup"
```

Hugo 0.116 or newer. No npm, no external fonts, no external requests at runtime.

## Content model

| Path | Purpose |
| --- | --- |
| `content/about.md` | The about page (single page) |
| `content/blog/*.md` | Blog entries |
| `content/blog/_index.md` | Blog list intro (title + intro text) |
| `content/landing/*.md` | Landing entries, rendered as cards on the home page |

`content/landing/_index.md` carries `build = { list = 'never', render = 'never' }` so
the section itself is not published — the entries appear on `/` as cards.

Landing entries accept `weight` (card order) and `link` (point a card at an
external URL instead of its own page).

### Blog front matter

```toml
+++
title = "Why we run a plural meetup"
date = 2026-10-14
summary = "One sentence for the list view."
description = "Optional longer lede on the entry page."
tags = ["community", "events"]
categories = ["announcements"]
+++
```

Tags and categories are taxonomies; `/tags/` and `/categories/` are built
automatically.

## Navigation rules

The top bar is generated by the theme, so links only exist when their content does:

- **Home** — always shown (`/`).
- **About** — shown only when `content/about.md` exists.
- **Blog** — shown only when at least one blog entry exists.

Nothing in the top bar can point at a URL that would 404. The same rule applies to
the landing page's call-to-action buttons.

## Theming

Precedence, highest first:

1. The dropdown in the top bar (stored in `localStorage`).
2. The OS setting (`prefers-color-scheme`).
3. Dark — the default.

Selecting **System** clears the stored choice and hands control back to the OS.
The theme is applied before first paint, so there is no flash of the wrong palette.

| Mode | Background | Text | Accent |
| --- | --- | --- | --- |
| Dark (default) | `#000000` | `#E9E9EF` | green `#31C69E` |
| Light | `#FFFFFF` | `#17171F` | purple `#6B3FBD` |
| High contrast | `#000000` | `#FFFFFF` | green `#31C69E`, 2 px borders, underlined links |

Brand colours: purple `#6B3FBD`, blue `#347DDE`, green `#31C69E`, black `#000000`.

## Configuration

All optional, set under `[params]` in `hugo.toml`:

| Parameter | Default | Purpose |
| --- | --- | --- |
| `description`, `tagline`, `author` | — | Hero copy and meta tags |
| `about_page` | `/about` | Path of the about page |
| `blog_section` | `blog` | Section that holds blog entries |
| `landing_section` | `landing` | Section that holds landing entries |
| `landing_heading` | `What we do` | Heading above the landing cards |
| `cta_blog`, `cta_about` | `Read the blog`, `About us` | Hero buttons |
| `nav_home_label`, `nav_about_label`, `nav_blog_label` | `Home`, `About`, `Blog` | Top bar labels |
| `theme_label` and `theme_option_*` | `Theme`, `System`, `Dark`, `Light`, `High contrast` | Switcher labels |
| `copyright_owner`, `copyright_suffix` | site title, `All rights reserved.` | Footer notice |
| `in_label` | `in` | Word before the category names on blog entries |

Pagination is set site-wide with Hugo's `paginate` (default here: 6).
